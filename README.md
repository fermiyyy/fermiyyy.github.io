# Subbs - Telegram Mini App

Telegram мини-приложение для заработка Telegram Stars через выполнение заданий и подписки на каналы.

## 🎨 Дизайн

Приложение выполнено в стиле **Soft Neo-Brutalism**:
- Фон: #FFFEF9 (кремовый)
- Карточки: #FFFFFF (белый)
- Текст и границы: #000000 (чёрный)
- Акцент: #FCD34D (золотисто-жёлтый)
- Толстые чёрные границы
- Жёсткие тени без размытия
- Крупные скругления

## ✨ Функционал

### Основные возможности:

1. **Система заданий**
   - Подписка на 6 каналов
   - Автоматическая проверка подписки в течение 7 дней
   - Если пользователь отписывается - блокировка получения новых подарков до повторной подписки и недельного ожидания
   - Награда за выполнение всех заданий: 15 Telegram Stars (подарок "сердце")

2. **Магазин подарков**
   - Сердце: 15 ⭐
   - Роза: 25 ⭐
   - Золото: 50 ⭐
   - Алмаз: 100 ⭐

3. **Заказ пиара канала**
   - Владельцы каналов платят 4-5 Telegram Stars за подписчика
   - Минимальный заказ: 10 подписчиков
   - Пользователи могут заказать пиар своего канала за звёзды

4. **Система проверки подписок**
   - Автоматическая проверка в течение недели
   - Блокировка получения подарков при обнаружении отписки
   - Требование повторной подписки и недельного ожидания

## 🚀 Установка и запуск

### Локальное тестирование

1. Откройте `index.html` в браузере
2. Приложение будет работать в демо-режиме с localStorage

### Настройка для Telegram Mini App

1. **Создание бота:**
   - Откройте [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните токен бота

2. **Создание Mini App:**
   - В [@BotFather](https://t.me/BotFather) отправьте `/newapp`
   - Выберите вашего бота
   - Укажите название приложения: `Subbs`
   - Укажите описание: `Зарабатывай Telegram Stars через подписки`
   - Загрузите иконку (512x512px)
   - Укажите URL вашего приложения (например: `https://yourdomain.com`)
   - Сохраните короткое имя для приложения

3. **Размещение файлов:**
   - Загрузите файлы на веб-сервер с HTTPS
   - Или используйте GitHub Pages, Netlify, Vercel для бесплатного хостинга

4. **Бот:** @SubbsApp_bot

## 📱 Использование

1. **Выполнение заданий:**
   - Перейдите в раздел "Задания"
   - Подпишитесь на все 6 каналов
   - Дождитесь проверки (7 дней)
   - Получите подарок после успешной проверки

2. **Покупка подарков:**
   - Накопите звёзды выполняя задания
   - Перейдите в "Магазин подарков"
   - Выберите подарок и купите его

3. **Заказ пиара:**
   - Перейдите в "Заказать пиар"
   - Введите ссылку на канал
   - Укажите количество подписчиков
   - Оплатите заказ звёздами

## 🔧 Технические детали

- **Frontend:** HTML, CSS (Tailwind), JavaScript
- **Telegram API:** Telegram WebApp API
- **Хранение данных:** localStorage (для демо)
- **Проверка подписок:** Симуляция (в продакшене нужен backend с Telegram Bot API)

## 📝 Примечания

- Для полноценной работы требуется backend для:
  - Проверки реальных подписок через Telegram Bot API
  - Обработки платежей Telegram Stars
  - Управления заказами на пиар
  - Хранения данных пользователей

# 🚀 Быстрый старт

## Локальный запуск для тестирования

1. Откройте `index.html` в браузере
2. Приложение будет работать в демо-режиме с localStorage

## Настройка для Telegram Mini App

### Шаг 1: Создание бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните токен бота

### Шаг 2: Создание Mini App

1. В [@BotFather](https://t.me/BotFather) отправьте `/newapp`
2. Выберите вашего бота
3. Укажите название приложения: `Subbs`
4. Укажите описание: `Зарабатывай Telegram Stars через подписки`
5. Загрузите иконку (512x512px)
6. Укажите URL вашего приложения (например: `https://yourdomain.com`)
7. Сохраните короткое имя для приложения

### Шаг 3: Размещение файлов

Загрузите файлы на веб-сервер:
- `index.html`
- `app.js`
- `config.js` (опционально)

Или используйте GitHub Pages, Netlify, Vercel для бесплатного хостинга.

### Шаг 4: Настройка каналов

Откройте `app.js` и измените массив `channels` в объекте `state`:

```javascript
channels: [
    { id: 1, name: 'Ваш канал 1', username: '@yourchannel1', link: 'https://t.me/yourchannel1' },
    { id: 2, name: 'Ваш канал 2', username: '@yourchannel2', link: 'https://t.me/yourchannel2' },
    // ... добавьте свои каналы
]
```

### Шаг 5: Настройка подарков

Измените массив `gifts` в `app.js`:

```javascript
gifts: [
    { id: 1, name: 'сердце', emoji: '❤️', cost: 15, description: 'базовый подарок' },
    // ... добавьте свои подарки
]
```

## 🔧 Настройка цен

### Стоимость пиара

В `app.js` найдите константу:
```javascript
const PROMO_COST_PER_SUB = 4.5; // Измените на нужное значение
```

### Награда за задания

```javascript
const GIFT_REWARD = 15; // Количество звёзд за выполнение всех заданий
```

## 📱 Тестирование

1. Откройте вашего бота в Telegram
2. Нажмите на кнопку Mini App (или отправьте команду `/start`)
3. Протестируйте все функции:
   - Подписка на каналы
   - Получение подарков
   - Покупка подарков
   - Заказ пиара

## ⚠️ Важно

- Для полноценной работы нужен backend (см. `BACKEND_INTEGRATION.md`)
- Проверка подписок сейчас симулируется (в продакшене нужен реальный API)
- Платежи Telegram Stars требуют настройки на backend
- Все данные хранятся в localStorage (для продакшена нужна БД)

## 🎨 Кастомизация дизайна

Все стили находятся в `<style>` блоке в `index.html`. Основные цвета:

- Фон: `#FFFEF9`
- Карточки: `#FFFFFF`
- Текст: `#000000`
- Акцент: `#FCD34D`

Измените эти значения для кастомизации под ваш бренд.

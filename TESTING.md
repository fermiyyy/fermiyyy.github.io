# 🧪 Руководство по тестированию

## Тестирование в Telegram Mini App

### Предварительные требования

1. Бот создан через [@BotFather](https://t.me/BotFather)
2. Mini App настроен и привязан к боту
3. URL приложения доступен по HTTPS

### Тестирование на мобильных устройствах

#### iOS (iPhone/iPad)

1. Откройте бота @SubbsApp_bot в Telegram
2. Нажмите на кнопку Mini App
3. Проверьте:
   - ✅ Корректное отображение на всех размерах экрана
   - ✅ Работа навигации
   - ✅ Отсутствие проблем с клавиатурой
   - ✅ Корректные отступы safe area (для iPhone с вырезом)
   - ✅ Плавная прокрутка
   - ✅ Работа всех кнопок и форм

#### Android

1. Откройте бота @SubbsApp_bot в Telegram
2. Нажмите на кнопку Mini App
3. Проверьте:
   - ✅ Корректное отображение
   - ✅ Работа навигации
   - ✅ Отсутствие проблем с клавиатурой
   - ✅ Плавная прокрутка
   - ✅ Работа всех кнопок и форм

### Тестирование функционала

#### 1. Система заданий

- [ ] Подписка на канал открывает правильную ссылку
- [ ] Подписка регистрируется в системе
- [ ] Статус "проверка..." отображается корректно
- [ ] Таймер обратного отсчёта работает
- [ ] После 7 дней подписка проверяется
- [ ] При отписке статус меняется на "failed"
- [ ] При повторной подписке таймер сбрасывается
- [ ] Подарок выдаётся только после проверки всех подписок

#### 2. Магазин подарков

- [ ] Все подарки отображаются
- [ ] Стоимость отображается корректно
- [ ] Кнопка "купить" открывает Telegram Stars invoice
- [ ] После оплаты подарок помечается как полученный
- [ ] Нельзя купить подарок дважды
- [ ] При недостатке звёзд показывается ошибка
- [ ] При наличии отписок покупка блокируется

#### 3. Заказ пиара

- [ ] Форма валидирует ссылку на канал
- [ ] Минимальное количество подписчиков проверяется
- [ ] Стоимость рассчитывается автоматически
- [ ] При изменении количества обновляется стоимость
- [ ] Кнопка "заказать" открывает Telegram Stars invoice
- [ ] После оплаты заказ создаётся
- [ ] История заказов отображается корректно

#### 4. Профиль и статистика

- [ ] Данные пользователя загружаются из Telegram
- [ ] Аватар отображается (если доступен)
- [ ] Статистика обновляется в реальном времени
- [ ] Баланс звёзд отображается корректно

### Тестирование Telegram Stars API

#### Покупка подарка

1. Перейдите в "Магазин подарков"
2. Выберите подарок
3. Нажмите "Купить"
4. Должно открыться окно оплаты Telegram Stars
5. После оплаты подарок должен быть получен

#### Заказ пиара

1. Перейдите в "Заказать пиар"
2. Заполните форму
3. Нажмите "Заказать пиар"
4. Должно открыться окно оплаты Telegram Stars
5. После оплаты заказ должен быть создан

### Известные ограничения

1. **Проверка подписок**: В демо-режиме используется симуляция. В продакшене нужен backend с Telegram Bot API.

2. **Telegram Stars**: Для работы в реальном Telegram нужен настроенный бот с поддержкой Stars.

3. **Хранение данных**: В текущей версии используется localStorage. Для продакшена нужна база данных.

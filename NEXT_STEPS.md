## 🌐 Шаг 2: Размещение на GitHub Pages

### 2.1. Создайте репозиторий на GitHub

1. Перейдите на [github.com](https://github.com)
2. Создайте новый репозиторий (например, `subbs-mini-app`)
3. **НЕ** добавляйте README, .gitignore или лицензию (у вас уже есть файлы)

### 2.2. Загрузите файлы

```bash
# В терминале в папке проекта выполните:
git init
git add .
git commit -m "Initial commit: Subbs Mini App"
git branch -M main
git remote add origin https://github.com/ВАШ_USERNAME/subbs-mini-app.git
git push -u origin main
```

Или используйте GitHub Desktop / VS Code для загрузки файлов.

### 2.3. Настройте GitHub Pages

1. Перейдите в настройки репозитория: `Settings` → `Pages`
2. В разделе "Source" выберите: **GitHub Actions**
3. Сохраните настройки
4. GitHub автоматически задеплоит приложение через несколько минут

### 2.4. Получите URL

После деплоя вы получите URL вида:
```
https://ВАШ_USERNAME.github.io/subbs-mini-app/
```

## 🤖 Шаг 3: Настройка Telegram бота

### 3.1. Создайте бота (если ещё не создан)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Сохраните токен бота

### 3.2. Создайте Mini App

1. В [@BotFather](https://t.me/BotFather) отправьте `/newapp`
2. Выберите вашего бота
3. Заполните данные:
   - **Title:** `Subbs`
   - **Description:** `Зарабатывай Telegram Stars через подписки`
   - **Photo:** Загрузите иконку 512x512px
   - **Short name:** `subbs` (или другое уникальное имя)
   - **Web App URL:** `https://ВАШ_USERNAME.github.io/subbs-mini-app/`
4. Сохраните

### 3.3. Настройте кнопку меню

1. В [@BotFather](https://t.me/BotFather) отправьте `/mybots`
2. Выберите вашего бота
3. Выберите `Bot Settings` → `Menu Button`
4. Выберите `Configure menu button`
5. Введите текст: `Открыть приложение`
6. Выберите `Web App`
7. Выберите ваше Mini App

## 🐛 Если что-то не работает

### Проблема: Кнопки не работают

1. Откройте консоль браузера (F12)
2. Проверьте наличие ошибок
3. Убедитесь, что `app.js` загружается
4. Очистите кэш браузера (Ctrl+Shift+R)

### Проблема: GitHub Pages не работает

1. Проверьте, что файлы загружены в репозиторий
2. Проверьте Actions tab - есть ли ошибки деплоя
3. Убедитесь, что в настройках выбран "GitHub Actions" как источник

### Проблема: Mini App не открывается

1. Проверьте URL в настройках бота
2. Убедитесь, что URL доступен (откройте в браузере)
3. Проверьте, что используется HTTPS

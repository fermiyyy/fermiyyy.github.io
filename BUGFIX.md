# 🐛 Исправление проблемы с кнопками

## Проблема
Кнопки не работали из-за того, что функции не были доступны глобально до их использования в onclick handlers.

## Решение

### 1. Глобальная доступность функций
- Все функции теперь доступны через `window` объект
- Функция `makeFunctionsGlobal()` вызывается в конце файла после определения всех функций
- Также вызывается при инициализации приложения для надёжности

### 2. Правильная инициализация
- Функции определяются глобально до использования
- Добавлена обработка ошибок при инициализации
- Проверка доступности функций после загрузки

### 3. Обработка ошибок
- Добавлена обработка ошибок в HTML
- Проверка загрузки скрипта
- Сообщения об ошибках для пользователя

## Проверка

Откройте консоль браузера (F12) и проверьте:
1. Нет ли ошибок JavaScript
2. Функции доступны: `typeof window.showScreen === 'function'`
3. Приложение инициализировано: проверьте логи в консоли

## GitHub Pages

Создан файл `.github/workflows/deploy.yml` для автоматического деплоя на GitHub Pages.

### Настройка:
1. В настройках репозитория включите GitHub Pages
2. Выберите источник: GitHub Actions
3. При каждом push в main/master будет автоматический деплой

## Тестирование

1. Откройте `index.html` в браузере
2. Проверьте работу всех кнопок:
   - Навигация внизу
   - Кнопки на главном экране
   - Кнопки в заданиях
   - Кнопки в магазине подарков
   - Форма заказа пиара

3. Откройте консоль (F12) и проверьте отсутствие ошибок

## Если кнопки всё ещё не работают

1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что `app.js` загружается (проверьте Network tab)
3. Проверьте, что функции доступны: `console.log(window.showScreen)`
4. Очистите кэш браузера (Ctrl+Shift+R)
